How to generate og-image.png:
  1. Open this file in Chrome: file:///.../assets/og-image.html (or via the local dev server).
  2. Open DevTools (F12) → right-click the <div id="card"> element in the Elements panel → Capture node screenshot. Chrome saves a 1200×630 PNG at exact resolution.
  3. Rename the saved file to og-image.png and drop it in this same assets/ folder.
  4. Commit assets/og-image.png alongside any index.html changes. GitHub Pages will serve it at the URL referenced by the og:image meta tag.

Alternative: take a 1200×630 screenshot with any tool (ShareX, Greenshot) and crop precisely. OG crawlers (Discord, Slack, Reddit, Twitter) want 1.91:1 aspect and at least 1200 wide.
